One folder = one period. To add one: copy a folder, rename it, edit periodo.json,
then run  python build.py  (or  python build.py --ha  to also copy it into Home Assistant).
Optional images in the period folder:
  sfondo.png (both modes)  or  sfondo-light.png + sfondo-dark.png
  decorazioni/alto-sinistra.png, alto-destra.png, basso-sinistra.png, basso-destra.png,
              alto-centro.png, basso-centro.png   (dark variant: alto-sinistra.dark.png)
Folders starting with _ are ignored (handy to disable a period).
